## Addressing

- Pattern `ME.<rest>` -> `spec://ai.lev/fpf-eng-me/contract/ME-<rest>#root` (every dot of the id becomes a dash; core ids start with their part letter, `A.4` -> `contract/A-4`). Example: `spec://ai.lev/fpf-eng-me/contract/ME-1#root`.
- Working sections (Problem frame, Problem, Forces, Solution, Conformance Checklist, Consequences, Relations) are in `contract/`; depth sections (Archetypal Grounding, Bias-Annotation, Anti-Patterns, Rationale, SoTA-Echoing) are in `source/`: `spec://ai.lev/fpf-eng-me/source/ME-1#depth`. The last line of every contract names its source with `#source`.
- Section anchors are the FPF section names: `#problem-frame`, `#solution`, `#conformance-checklist`, `#dependencies`; named rules `CC-…` are facts (`CC-A-4-1`).
- Table of Contents with keywords, dependencies and a Reading column: `spec://ai.lev/fpf-eng-me/pub/TOC#root`.
